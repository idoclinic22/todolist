# AK 강의 투두 리스트 — 기획서

> 최종 수정: 2026-09-02

---

## 1. 개요

AK(응용근신경학) 한의사 교육/강의를 진행하는 강사가 **강좌별로 준비할 일**을
관리하는 개인용 웹앱. 서버·데이터베이스·로그인 없이 내 PC 브라우저에서 열어
사용하며, 브라우저에 저장한 내용은 새로고침하거나 나중에 다시 열어도 그대로 남는다.

- **플랫폼**: 웹 (데스크톱 브라우저 위주)
- **기술**: Next.js (App Router) + TypeScript
- **저장소**: 브라우저 `localStorage` (DB 없음)
- **사용자 수**: 1인 (개인용, 공유 불필요)

---

## 2. 목표와 배경

| 항목 | 내용 |
|------|------|
| 문제 | 강의 준비 할 일이 여러 강좌에 흩어져 있어 한눈에 관리가 어렵다 |
| 목표 | 강좌 단위로 할 일을 묶어 추가·완료·수정·삭제하고, 우선순위로 정렬한다 |
| 제약 | 설치/서버/DB 없이 브라우저만으로 동작, 기록은 영구 보존 |
| 성공 기준 | 새로고침·재방문 후에도 입력한 강좌와 할 일이 100% 유지된다 |

---

## 3. 사용자 시나리오

1. "AK 기초과정 3기" 강좌를 만든다.
2. 그 아래 "1강 슬라이드 정리", "실습 도구 준비", "수강생 명단 확인"을 추가한다.
3. "실습 도구 준비"를 **우선순위 높음**으로 올려 목록 위쪽으로 정렬되게 한다.
4. "1강 슬라이드 정리"에 강의 날짜(2026-09-10)를 단다.
5. 준비가 끝난 항목은 체크 → 완료 표시(취소선). 화면이 복잡하면 **"진행 중"** 필터로 정리.
6. 며칠 뒤 브라우저를 다시 열어도 모든 내용이 그대로 있다.

## 4. 기능 명세

### 4.1 강좌(그룹)

| ID | 기능 | 상세 |
|----|------|------|
| C1 | 강좌 추가 | 상단 입력창에 이름 입력 → 새 강좌 섹션 생성 |
| C2 | 강좌 이름 수정 | 헤더의 강좌명 클릭 → 인라인 편집 (Enter 저장 / Esc 취소) |
| C3 | 강좌 삭제 | 삭제 버튼 → **확인 모달** → 강좌와 하위 할 일 모두 삭제 |
| C4 | 진행 현황 표시 | 헤더에 `완료수 / 전체수` 배지 (예: 3 / 8) |

### 4.2 할 일

| ID | 기능 | 상세 |
|----|------|------|
| T1 | 할 일 추가 | 강좌 섹션 안 입력창에 텍스트 입력 → 추가 (빈 값·공백 무시) |
| T2 | 완료 토글 | 체크박스 클릭 → 완료 시 취소선 + 흐리게, 목록 하단으로 이동 |
| T3 | 할 일 수정 | 텍스트 더블클릭(또는 편집 버튼) → 인라인 편집 |
| T4 | 할 일 삭제 | 항목 삭제 버튼 (호버 시 노출) |
| T5 | 우선순위 | 높음 / 보통 / 낮음 — 색 라벨, 변경 시 즉시 재정렬 |
| T6 | 강의 날짜 (선택) | 항목별 `날짜` 지정 가능, 비워두면 표시 안 함. 지난 날짜=빨강, 오늘=포인트색 |

### 4.3 필터 / 정렬

| ID | 기능 | 상세 |
|----|------|------|
| F1 | 완료 필터 | 강좌별 탭: **전체 / 진행 중 / 완료** (기본값: 전체) |
| F2 | 자동 정렬 | ① 미완료 우선 → ② 우선순위(높음>보통>낮음) → ③ 추가한 순서 |

### 4.4 저장 (영속성)

| ID | 기능 | 상세 |
|----|------|------|
| S1 | 자동 저장 | 모든 변경이 즉시 `localStorage`에 기록 (저장 버튼 없음) |
| S2 | 자동 복원 | 페이지 로드 시 `localStorage`에서 읽어 화면 복원 |
| S3 | 안전 처리 | 저장 데이터가 손상됐거나 `localStorage` 사용 불가 시 → 빈 상태로 시작, 안내 배너 표시 |

## 5. 데이터 모델

`localStorage` 키 **`ak-todo:v1`** 하나에 아래 JSON을 저장한다.

```jsonc
{
  "version": 1,
  "courses": [
    {
      "id": "9f2c...",           // crypto.randomUUID()
      "name": "AK 기초과정 3기",
      "order": 0,                 // 강좌 표시 순서
      "createdAt": 1756800000000
    }
  ],
  "todos": [
    {
      "id": "1a7b...",
      "courseId": "9f2c...",      // 소속 강좌
      "text": "1강 슬라이드 정리",
      "done": false,
      "priority": "high",         // "high" | "normal" | "low"
      "dueDate": "2026-09-10",    // "YYYY-MM-DD" 또는 null
      "order": 0,                  // 강좌 내 추가 순서
      "createdAt": 1756800000000
    }
  ]
}
```

## 6. 화면 구성 (깔끔한 미니멀 · 라이트)

```
┌───────────────────────────────────────────────┐
│  AK 강의 할 일                                   │
│  [ 새 강좌 이름............... ]  ( + 강좌 추가 ) │
├───────────────────────────────────────────────┤
│  ▸ AK 기초과정 3기            3 / 8   [수정][삭제]│
│    [ 전체 | 진행 중 | 완료 ]                     │
│    [ 할 일 입력............... ]  ( 추가 )        │
│    ☐ 실습 도구 준비        [높음] [2026-09-10] ⋯ │
│    ☐ 수강생 명단 확인      [보통]              ⋯ │
│    ☑ 1강 슬라이드 정리     [낮음]  (취소선/흐림)   │
├───────────────────────────────────────────────┤
│  ▸ 온라인 강의 촬영          0 / 2   [수정][삭제] │
│    ...                                          │
└───────────────────────────────────────────────┘
```

- 흰 배경, 본문 중앙 정렬(max-width ≈ 720px), 시스템 폰트, 한 가지 포인트 컬러
- 강좌 = 은은한 보더/그림자의 카드 섹션
- 우선순위 색: 높음(빨강 계열) · 보통(중립) · 낮음(연회색)
- 항목 액션(편집/삭제/날짜)은 마우스 호버 시 노출해 평소엔 깔끔하게
- 빈 상태 문구: "아직 강좌가 없습니다" / "이 강좌에 할 일이 없습니다"

## 7. 비기능 요구사항

- **DB·서버 API 없음**: 100% 클라이언트, 정적 배포만으로 동작
- **오프라인 사용 가능**
- **SSR 안전**: 서버 렌더 시 빈 상태 → 클라이언트 마운트 후 `localStorage` 로드 (hydration 오류 방지)
- **반응형**: 모바일 폭에서도 레이아웃이 무너지지 않음
- **접근성**: 체크박스·버튼에 라벨, 키보드로 추가/편집 가능
